The moat — what makes this hard

CACHE
Anthropic prompt cache on static system prompt tier (domain vocab, tool specs, playbook). ~90% token reuse · 5× cost reduction
TOOLS
Typed Zod tool layer — 12 read tools, 3 write tools. Write tools gated, invoked post-approval only. no free-form SQL · bounded at 8 turns
DATA
pgvector for free-text signatures · deterministic SQL for structured queries. embeddings FLOAT8[] · 1536-dim · cosine
DATA
Lessons embed resolved incidents; retrieved on Classify → biases archetype prior. cross-plant network effect
GUARD
Evidence-cite contract: every claim cites a tool_call_id. Validator blocks output with orphaned refs. one retry · second failure = hard error
GUARD
Closure predicates — typed JSON, evaluated by cron. A resolution is not stampable; it has to measurably close. no humans marking tickets "done"
