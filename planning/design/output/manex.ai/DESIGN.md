# Design System

## Overview
Design tokens extracted from manex.ai.

## Colors
- **Primary** (#639fc4): CTAs, active states, key interactive elements
- **Secondary** (#000000): Supporting UI, secondary actions
- **Surface** (#ffffff): Page backgrounds
- **On-surface** (#160042): Primary text

## Typography
- **Headlines**: DM Sans, bold, 11.2–56px

## Components
- **Buttons**: Rounded (3.75px), primary uses #1032cf fill, outlined variant available
- **Inputs**: 1px solid border, 8px radius
- **Border radius scale**: 3.75px, 4px, 7.5px, 8px
- **Elevation**: uses box shadows for depth

## Do's and Don'ts
- Do use rounded corners consistently across interactive elements
- Do use the primary color sparingly — only for the most important action per screen
- Do maintain 4.5:1 contrast ratio for all body text (WCAG AA)
